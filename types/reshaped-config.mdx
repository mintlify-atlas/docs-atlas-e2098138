The `ReshapedConfig` type defines the structure for configuring custom themes, theme fragments, and theming options in Reshaped.

## Type Definition

```typescript
export type ReshapedConfig = {
  themes?: Record<string, PassedThemeDefinition>;
  themeFragments?: Record<string, PassedThemeDefinition>;
  themeOptions?: {
    colorOutputFormat?: "oklch" | "hex";
    colorContrastAlgorithm?: "wcag" | "apca";
    generateOnColorsFor?: string[];
    onColorValues?: {
      [key in Hue]?:
        | {
            hexDark: HexColor;
            hexLight: HexColor;
          }
        | {
            oklchDark: OklchColor;
            oklchLight: OklchColor;
          };
    };
  };
};
```

Source: `packages/reshaped/src/types/config.ts:4-23`

## Overview

`ReshapedConfig` is used in `reshaped.config.ts` to define:
- Custom themes with complete or partial token overrides
- Reusable theme fragments for brand colors
- Global theming options for color generation and formats

## Configuration Properties

### themes

Define custom themes that can be used with the `Reshaped` component:

```typescript
import type { ReshapedConfig } from "reshaped";

const config: ReshapedConfig = {
  themes: {
    custom: {
      color: {
        backgroundPrimary: { hex: "#0D99FF", hexDark: "#0C8CE9" },
        foregroundPrimary: { hex: "#007BE5", hexDark: "#7CC4F8" },
      },
      fontFamily: {
        body: { family: "Inter, sans-serif" },
      },
    },
  },
};

export default config;
```

### themeFragments

Create reusable color fragments for brand integration:

```typescript
const config: ReshapedConfig = {
  themeFragments: {
    twitter: {
      color: {
        backgroundPrimary: { hex: "#1da1f2" },
        backgroundPrimaryHighlighted: { hex: "#1a90da" },
        onBackgroundPrimary: { hex: "#ffffff" },
      },
    },
    spotify: {
      color: {
        backgroundPrimary: { hex: "#1DB954" },
        backgroundPrimaryHighlighted: { hex: "#1aa34a" },
        onBackgroundPrimary: { hex: "#ffffff" },
      },
    },
  },
};
```

See the example at `packages/reshaped/src/cli/theming/reshaped.config.ts:14-22`.

### themeOptions

Configure global theming behavior:

#### colorOutputFormat

Choose the CSS color format for generated themes:

```typescript
const config: ReshapedConfig = {
  themeOptions: {
    // Use OKLCH for better color interpolation
    colorOutputFormat: "oklch",
    
    // Or use HEX for wider browser support
    // colorOutputFormat: "hex",
  },
};
```

<Info>
  OKLCH provides perceptually uniform color interpolation but requires modern browsers.
  HEX has universal support but less accurate color mixing.
</Info>

#### colorContrastAlgorithm

Select the contrast calculation algorithm:

```typescript
const config: ReshapedConfig = {
  themeOptions: {
    // WCAG 2.1 (default) - widely adopted standard
    colorContrastAlgorithm: "wcag",
    
    // Or APCA - newer, more accurate for modern displays
    // colorContrastAlgorithm: "apca",
  },
};
```

<CardGroup cols={2}>
  <Card title="WCAG" icon="check">
    Industry standard, required for accessibility compliance. Uses contrast ratios (4.5:1, 3:1).
  </Card>
  
  <Card title="APCA" icon="wand-magic-sparkles">
    Modern algorithm accounting for font weight and size. Provides more nuanced contrast scores.
  </Card>
</CardGroup>

#### generateOnColorsFor

Specify which color hues should have "on" colors automatically generated:

```typescript
const config: ReshapedConfig = {
  themeOptions: {
    generateOnColorsFor: ["primary", "positive", "critical", "warning"],
  },
};
```

"On" colors are foreground colors optimized for use on colored backgrounds, ensuring readability.

#### onColorValues

Manually specify "on" colors for precise control:

```typescript
const config: ReshapedConfig = {
  themeOptions: {
    onColorValues: {
      primary: {
        hexLight: "#ffffff",  // Text on primary background in light mode
        hexDark: "#000000",   // Text on primary background in dark mode
      },
      positive: {
        oklchLight: { l: 0.95, c: 0.05, h: 150 },
        oklchDark: { l: 0.15, c: 0.05, h: 150 },
      },
    },
  },
};
```

See example at `packages/reshaped/src/tests/themes.stories.tsx:357-363`.

## Complete Example

Example from the Reshaped source:

```typescript
import figmaDefinition from "@/themes/_generator/definitions/figma";
import reshapedDefinition from "@/themes/_generator/definitions/reshaped";
import slateDefinition from "@/themes/_generator/definitions/slate";
import type { ReshapedConfig } from "@/types/config";

const config: ReshapedConfig = {
  themes: {
    reshaped: reshapedDefinition,
    figma: figmaDefinition,
    slate: slateDefinition,
  },

  themeFragments: {
    twitter: {
      color: {
        backgroundPrimary: { hex: "#1da1f2" },
        backgroundPrimaryHighlighted: { hex: "#1a90da" },
        onBackgroundPrimary: { hex: "#ffffff" },
      },
    },
  },
};

export default config;
```

## Theme Definition Structure

A `PassedThemeDefinition` can include:

<AccordionGroup>
  <Accordion title="color - Color tokens">
    Define colors for backgrounds, foregrounds, and borders in both light and dark modes.
    
    ```typescript
    color: {
      backgroundPrimary: { hex: "#0D99FF", hexDark: "#0C8CE9" },
      foregroundNeutral: { hex: "#191919", hexDark: "#FFFFFF" },
      borderPrimary: { hex: "#007BE5", hexDark: "#7CC4F8" },
    }
    ```
  </Accordion>
  
  <Accordion title="fontFamily - Typography families">
    Define font stacks for different text purposes.
    
    ```typescript
    fontFamily: {
      title: { family: "Inter, sans-serif" },
      body: { family: "Inter, sans-serif" },
      monospace: { family: "Menlo, Monaco, monospace" },
    }
    ```
  </Accordion>
  
  <Accordion title="fontWeight - Font weights">
    Define named font weights.
    
    ```typescript
    fontWeight: {
      regular: { weight: 400 },
      medium: { weight: 500 },
      semibold: { weight: 600 },
      bold: { weight: 700 },
    }
    ```
  </Accordion>
  
  <Accordion title="font - Text styles">
    Define complete text styles combining size, line height, weight, and family.
    
    ```typescript
    font: {
      title1: {
        fontSize: { px: 80 },
        lineHeight: { px: 84 },
        fontWeightToken: "semibold",
        fontFamilyToken: "title",
      },
      body1: {
        fontSize: { px: 14 },
        lineHeight: { px: 20 },
        fontFamilyToken: "body",
      },
    }
    ```
  </Accordion>
  
  <Accordion title="unit - Spacing and sizing">
    Define base units for spacing and border radius.
    
    ```typescript
    unit: {
      base: { px: 4 },
      radiusSmall: { px: 4 },
      radiusMedium: { px: 8 },
      radiusLarge: { px: 12 },
    }
    ```
  </Accordion>
  
  <Accordion title="radius - Border radius tokens">
    Define named border radius values.
    
    ```typescript
    radius: {
      small: { token: "radiusSmall" },
      medium: { token: "radiusMedium" },
      large: { token: "radiusLarge" },
      circular: { percent: 50 },
    }
    ```
  </Accordion>
  
  <Accordion title="shadow - Elevation shadows">
    Define shadow tokens for elevation.
    
    ```typescript
    shadow: {
      raised: [{
        offsetX: 0,
        offsetY: 1,
        blurRadius: 3,
        colorToken: "black",
        opacity: 0.15,
      }],
    }
    ```
  </Accordion>
  
  <Accordion title="duration - Animation durations">
    Define timing durations for animations.
    
    ```typescript
    duration: {
      rapid: { ms: 100 },
      fast: { ms: 200 },
      medium: { ms: 300 },
      slow: { ms: 400 },
    }
    ```
  </Accordion>
  
  <Accordion title="easing - Animation easings">
    Define easing curves for animations.
    
    ```typescript
    easing: {
      standard: { x1: 0.4, y1: 0, x2: 0.2, y2: 1 },
    ```

## Using the Configuration

<Steps>
  <Step title="Create reshaped.config.ts">
    Create a configuration file in your project root:
    
    ```typescript
    // reshaped.config.ts
    import type { ReshapedConfig } from "reshaped";
    
    const config: ReshapedConfig = {
      themes: {
        custom: {
          // Your theme definition
        },
      },
    };
    
    export default config;
    ```
  </Step>
  
  <Step title="Generate theme files">
    Use the Reshaped CLI to generate CSS from your config:
    
    ```bash
    npx reshaped theme
    ```
  </Step>
  
  <Step title="Apply the theme">
    Use your custom theme in your application:
    
    ```tsx
    import { Reshaped } from "reshaped";
    import "./themes/custom/theme.css";
    
    export default function App() {
      return (
        <Reshaped theme="custom">
          {/* Your app */}
        </Reshaped>
      );
    }
    ```
  </Step>
</Steps>
